Welcome to IMAP MCP Pro

This installer will set up IMAP MCP Pro v2.13.1 on your Mac.

IMAP MCP Pro provides AI-powered email management through Claude Desktop, with a web-based dashboard for account configuration, monitoring, and control.

What gets installed:

  • IMAP MCP Pro server — with bundled Node.js v22 runtime (no separate install required)
  • Web UI Dashboard — accessible at http://localhost:4500
  • ImapMCPControl — menu bar app for quick service control
  • LaunchAgent — auto-starts the service at login

After installation:

  • The web UI will open automatically in your browser
  • Look for the IMAP MCP icon in your menu bar
  • Add your email accounts through the web dashboard
  • Configure Claude Desktop using the setup instructions in the dashboard

Requirements:

macOS 13 (Ventura) or later  •  500 MB free disk space
